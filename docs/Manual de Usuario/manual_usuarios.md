**INTRODUCCIÓN**

Este manual tiene como objetivo guiar a los empleados en el uso del Punto de Venta (POV), explicando el uso de cada uno de los apartados, su funcionalidad y todas las operaciones necesarias para controlarlo.

**REQUISITOS DEL SISTEMA**

El Punto de Venta es un sistema disponible para acceder en todo momento y en cualquier lugar, para acceder al sistema es indispensable contar con:

* Dispositivo con acceso a internet (Teléfono, Laptop, Tablet, etc).  
* Navegador (Se puede acceder con cualquier navegador, por ejemplo Google, Microsoft Edge, Brave, etc).

**ACCESO AL SISTEMA**

El usuario puede acceder a la plataforma mediante el siguiente link: [https://bk.bunnyklin.com/signin](https://bk.bunnyklin.com/signin)

**INTERFAZ**  
![Interfaz](images/interfaz.png)

Al iniciar sesión correctamente pasará a visualizar la interfaz completa, esta misma se compone de distintos elementos;

1. **Menú Lateral:** Es el menú que permite navegar entre los distintos apartados del sistema, en la parte superior contiene el nombre del negocio junto con el logotipo. Este mismo puede ocultarse con el botón que se encuentra al lado derecho.  
2. **Área de Trabajo:** Es la parte donde se muestra la información de todos los apartados y la única que cambiará al cambiar entre los distintos apartados.  
3. **Perfil:** Indica la cuenta con la que se accedió, menciona el nombre del usuario y permite cerrar sesión al dar clic en el icono del nombre y seleccionando “Cerrar Sesión”.

   
**APARTADOS**

Como se mencionó anteriormente, el punto de venta se compone de distintos apartados, cada uno tiene una funcionalidad y opciones distintas que conforman la funcionalidad. En el menú lateral los apartados se dividen en 3 partes, Principales, Catálogos y Operación.

**PRINCIPALES**

1. **Punto de Venta**

![Punto de Venta](images/punto_venta.png)

Es la pantalla principal que se visualiza al iniciar sesión. En este se realizan las ventas de los productos, servicios y suscripciones que el negocio maneja, las ventas pueden ser por medio de pago en efectivo y pago con tarjeta (Este último deberá usar la terminal de Mercado Pago para realizarse).

2. **Historial de Ventas**

![Historial de Ventas](images/historial_ventas.png)

Funciona para visualizar las ventas realizadas, sean recientes o anteriores: Pueden filtrarse según sean las necesidades y permite visualizar y eliminar los registros.

3. **Máquinas IoT**

![Maquinas IoT](images/maquinas_iot.png)

Es un apartado que se enfoca en monitorear el estado de tus equipos, el usuario puede ver el estado en el que se encuentran, el tiempo restante y añadir, editar o eliminar nuevos equipos.


**CATÁLOGOS**

Los apartados que se encuentran dentro de esta parte tienen una funcionalidad parecida, permitiendo añadir, editar, visualizar o eliminar los registros que se encuentren, pueden ser configurados para ser visibles o no visibles para el apartado de punto de venta, pero se diferencian por el uso que tienen. 

1. **Servicios**

![Servicios de Lavandería](images/servicios.png)

Dentro de este apartado se administran los distintos servicios que el negocio ofrece, sean servicios para el establecimiento o servicios para pedidos y clientes externos.

2. **Insumos**

![Productos](images/insumos.png)

En este apartado se administran los distintos productos que el negocio ofrece a los clientes, tanto productos para lavado (Detergente, Blanqueadores, etc.), como productos consumibles (Papas, Bebidas, etc).

3. **Suscripciones**

![Suscripciones](images/suscripciones.png)

Por último, este apartado administra las suscripciones que se manejan, pueden durar por varios meses y con distintas cantidades de lavado disponibles.

   
**OPERACIÓN**

Esta última parte concentra los apartados enfocados en operaciones más específicas con un uso más bajo.

1. **Pedidos y Encargos**

![Pedidos](images/pedido_encargo.png)

Dentro de este apartado se realizarán las ventas por pedido o encargo, los servicios registrados como encargos serán los únicos que aparecerán para ser vendidos.

2. **Clientes**

![Clientes](images/clientes.png)

En este apartado el usuario puede administrar a los clientes que han sido registrados a partir de la venta de una suscripción, en este mismo pueden ser registrados con sus datos en caso de requerir factura.

3. **Gestión de Personal**

![Empleados](images/empleados.png)

En este apartado se pueden administrar los distintos usuarios que tengan acceso al Punto de Venta, pueden ser registrados con un rol de administradores o empleados para limitar su acceso a distintas funciones. 

4. **Corte de Caja**

![Corte de Caja](images/corte_caja.png)

Este apartado proporciona un control para el corte de caja, con el cual pueden recopilar las ventas, gastos y retiros que sucedan durante el turno del empleado. El usuario puede generar una factura global dentro de este mismo apartado y ver el historial de los distintos cortes que se hayan realizado en el sistema.

5. **Calendario**

![Calendario](images/calendario.png)

Funciona como un recurso visual para llevar el seguimiento de las fechas próximas en los pedidos y en las fechas de expiración de las suscripciones.

6. **Facturación**

![Facturación](images/facturacion.png)

En este último se enfoca en generar facturas para el cliente en caso de requerir, la factura se genera seleccionando una venta y un cliente.

**FUNCIONES PRINCIPALES**

El Punto de Venta se conforma de distintas funciones que al inicio pueden ser complejas de comprender, por ello en esta sección nos enfocaremos en explicar las operaciones de uso diario.

**CÓMO GENERAR UNA VENTA**

1. Ingresa al apartado de Punto de Venta.  
2. Selecciona el servicio, productos que desea el cliente.   
3. Revisa que los servicios y productos seleccionados en la canasta, dentro de esta pueden aumentar o disminuir la cantidad o eliminar el producto de la cuenta.

![Canasta](images/generar_venta2.png)

4. Da Clic en el botón de Cobrar Venta.  
5. Selecciona el método de pago.

![Completar Venta](images/generar_venta3.png)

6. Al seleccionar el método de pago genera la venta y aparecerá un mensaje donde menciona “\!Venta Exitosa¡”, seguido de ello da clic en Nueva Venta para regresar a la pantalla inicial.

![Venta Exitosa](images/generar_venta4.png)

**CÓMO GENERAR UNA VENTA DE SUSCRIPCIÓN**

1. Ingresa al apartado de Punto de Venta.  
2. Selecciona la suscripción que el cliente desee.  
3. Da Clic en el botón de Cobrar Venta.  

![Canasta](images/generar_venta_sub1.png)

4. Aparecerá una ventana donde primero se deberán de rellenar los siguientes campos con los datos del cliente.  
* ¿Para quién es la suscripción? Esta opción permite seleccionar si el cliente que compra la suscripción es nuevo o ya se encuentra registrado en el sistema (En el segundo caso solo es necesario seleccionar el cliente y puede proseguir con el siguiente paso).  
* Nombre Completo.  
* Teléfono.  
* Correo Electrónico.  
* Inicio de Plan: Es un campo que se genera en automático y no es editable  

![Completar Venta](images/generar_venta_sub2.png)

5. Al terminar de llenar los campos selecciona el método de pago.  
6. Al seleccionar el método de pago genera la venta y aparecerá un mensaje donde menciona “\!Venta Exitosa¡”, seguido de ello da clic en Nueva Venta para regresar a la pantalla inicial.

![Venta Exitosa](images/generar_venta4.png)


**CÓMO EDITAR LOS CAMPOS DEL TICKET QUE SE GENERA.**

1. Entra al apartado de Historial de Ventas.  
2. Selecciona alguna venta (no importa la venta que se seleccione).  
3. Ubícate en la parte del Visualizador y da clic en Editar Diseño.  
4. El ticket que se muestra entrará en modo de edición, dónde pueden editarse los siguientes campos:  
* Logotipo: Puede subirse un logotipo, pero es opcional.  
* Nombre del Negocio.  
* Dirección: Dirección del negocio.  
* Teléfono: Teléfono del negocio.  
* RFC o info. Extra: Puede ingresar el RFC del negocio o una información extra que se guste añadir.  
* Leyenda: En la parte inferior se puede cambiar la leyenda del ticket acerca de lo que quiera decir.  

![Editar Ticket](images/editar_ticket1.png)

5. Al terminar de editar da clic en Guardar Diseño para terminar la edición.


![Ticket](images/editar_ticket2.png)


**CÓMO REGISTRAR UN SERVICIO**

1. Entra al apartado de Servicios.  
2. Selecciona el botón de Registrar Servicio.  

![Nuevo Servicio](images/registrar_servicio1.png)

3. Se abrirá un formulario que deberá de rellenarse con los siguientes campos:  
* Elemento Activo: Permite seleccionar si el servicio aparecerá en el apartado de Punto de Venta.  
* Nombre.  
* Clave SAT: Se registra la clave del servicio que se ofrece, esta clave debe corresponder con un servicio del SAT, en caso de ser errónea generará conflicto al momento de facturar.  
* Precio.  
* Descripción: Detalles acerca del servicio.  
* Este servicio es por encargo: Campo seleccionable que menciona que el servicio que se registra es para venta en el establecimiento o para encargo.  

![Formulario de Registro](images/registrar_servicio2.png)

4. Al completar los campos da clic en el botón de Agregar para finalizar el registro.

![Editar Servicio](images/editar_servicio1.png)

**CÓMO REALIZAR LA FACTURA GLOBAL**

1. Entra al apartado de Corte de Caja.  
2. Realiza el corte de caja como se indicó (Esto es importante realizar ya que el registro de la factura se guarda junto con el corte generado anteriormente).  
3. Al completar el proceso da clic en el botón de Generar Factura Global.  

![Factura Global](images/factura_global0.png)

4. Abrirá una pequeña pantalla en donde debe indicarse la periocidad de la factura (en este caso sería Diaria).  

![Factura Global](images/factura_global1.png)

5. Da clic en Generar Factura Global para generarlo, al terminar de generarlo dará dos opciones, la primera permite visualizar el PDF que se genera y la segunda opción permite descargar el PDF junto con el archivo XML que se genera.

![Factura Global](images/factura_global2.png)

La factura debe de ser generada por el empleado que cierre el turno en horario nocturno, en caso de no realizarse en el sistema se mostrará que el corte de caja no realizó la factura del día.

**POSIBLES PROBLEMAS**



**ERROR AL FACTURAR**

Al momento de facturar pueden ocurrir errores o problemas, aquí mencionamos alguno de ellos.

1. **RFC INVALIDO**

Se registra un RFC inválido al momento de facturar, enviando un error al momento de generar la factura.

![RFC Invalido](images/error_rfc_invalido.png)

La solución a este problema es verificar que el RFC sea correcto, sea de una persona moral o una persona física debe corroborarse en caso de errores.

2. **CLAVE SAT INCORRECTA**

El sistema registra la clave del producto o servicio del SAT, esto es necesario ya que facilita el proceso de facturación, pero al ingresar una clave incorrecta el sistema lo identifica como un error.

![Clave SAT Incorrecta](images/error_clave_sat.png)

La solución es revisar la clave del producto o servicio y verificar que sea la correcta o esté bien escrita, después de ello puede intentarse de nuevo.

3. **PROBLEMA CON LAS LLAVES DE FACTURAPI**

El sistema obtiene una llave para vincular los servicios de Facturapi con el Punto de Venta, estos mismos tienen un tiempo límite, pueden existir dos casos usuales.

![Problemas de API](images/error_api_facturapi.png)

* Periodo Expirado: Puede ser causado porque el plan de prueba haya expirado o no se haya realizado el pago.   
    
  La solución es realizar el pago correspondiente.  
    
* Llave vencida: Las llaves de Facturapi tienen un tiempo de vencimiento, por lo cual deben ser actualizadas cuando ocurra el problema.  
    
  La solución será actualizar la llave de acceso dentro de Facturapi, reemplazarla dentro del código para que funcione de nuevo.

4. **CAMPOS NO SELECCIONADOS**

Para generar una factura es necesario completar todos los campos del formulario, en la falta de alguno de ellos puede provocar que el mensaje que la página refleje sea por ejemplo como el siguiente.

![Campos sin Completar](images/error_campo_faltante.png)

Este error se produce a causa de no seleccionar el método de pago con la que se realizó la venta, la corrección para este tipo de problemas es completar los campos de manera correcta y verificar que todos esten rellenados.
